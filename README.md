# Odisej Yacht Club (OYC) — konfigurator BALI A-2027

Aplikacja sprzedażowa zasilana oficjalnymi cennikami poszczególnych modeli BALI A-2027.

## Uruchomienie

```bash
npm install
npm run dev
```

Zdjęcia modeli można umieszczać w `public/images/` pod nazwami zgodnymi z identyfikatorami modeli, np. `bali-4-6.webp`.
