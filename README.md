# Odisej Yacht Club (OYC) — konfigurator BALI A-2026

Aplikacja sprzedażowa zasilana kompletnymi danymi z pliku `Zestawienie_modeli_BALI_A-2026.xlsx`.

## Uruchomienie

```bash
npm install
npm run dev
```

Zdjęcia modeli można umieszczać w `public/images/` pod nazwami zgodnymi z identyfikatorami modeli, np. `bali-4-6.webp`.
